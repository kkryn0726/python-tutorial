🔄 Python 可迭代对象（iterable）图文讲解

用「抽纸盒」这个类比，5 分钟看懂 for 循环背后的机制

一句话理解

可迭代对象 = 「能一个一个取出元素」的东西。就像一盒抽纸——你知道里面有纸，但需要一个抽纸口（迭代器），才能一张一张抽出来。

凡是可以放进 for 循环里遍历的，都是可迭代对象。

可迭代对象（数据容器） 迭代器（抽纸口+指针） next() 抽出的元素

哪些东西是可迭代对象？

类型例子说明
列表[1, 2, 3]最常用
元组(1, 2, 3)不可变，也能遍历
字符串"abc"逐个字符遍历
字典{"a":1}遍历的是键 key
集合{1, 2, 3}无序，能遍历
rangerange(5)数字序列
文件对象open("a.txt")逐行遍历
💡 反例：int、float 不是可迭代对象。for x in 5: 会报错 TypeError: 'int' object is not iterable。

核心：可迭代对象 ≠ 迭代器

这是最容易混的一对概念。记一句：

可迭代对象（iterable）：里面装着数据，本身没有"取到哪了"的状态。
迭代器（iterator）：负责取值，自带指针，记住当前位置。
# 可迭代对象 → 迭代器，靠 iter()
nums = [1, 2, 3]      # nums 是可迭代对象
it = iter(nums)           # it 是迭代器（有了指针）

# 迭代器 → 取元素，靠 next()
next(it)   # 1 —— 取一个，指针右移
next(it)   # 2
next(it)   # 3
next(it)   # 报错 StopIteration —— 取完了

for 循环背后，其实干了三件事

# 你写的：
for x in nums:
    print(x)

# Python 实际做的（等价于）：
it = iter(nums)        # 1️⃣ 拿迭代器
while True:
    try:
        x = next(it)   # 2️⃣ 不断 next() 取值
    except StopIteration:
        break             # 3️⃣ 取完就停
    print(x)
💡 所以 for 循环能遍历，本质就是「先 iter() 再反复 next()，取完捕获 StopIteration 结束」。你平时不用管，但理解它，迭代器和生成器就都不难了。

怎么判断是不是可迭代对象？

from collections.abc import Iterable

isinstance([1,2,3], Iterable)   # True  —— 列表是可迭代
isinstance("abc", Iterable)       # True  —— 字符串也可迭代
isinstance(123, Iterable)         # False —— 数字不可迭代
⚠️ 注意导入路径：要写 from collections.abc import Iterable。旧的 from collections import Iterable 在 Python 3.3+ 已废弃，新版会报 DeprecationWarning。

小结

  • 可迭代对象 = 能一个个取出元素的东西（列表、元组、字符串、字典、集合、range、文件…）。
  • 可迭代对象 ≠ 迭代器：前者装数据，后者带指针取值。
  • iter(对象) 拿到迭代器，next(迭代器) 取出下一个。
  • 取完会抛 StopIteration。
  • for 循环 = 自动 iter() + 反复 next() + 捕获 StopIteration。
  • 判断方法：isinstance(obj, Iterable)（从 collections.abc 导入）。
